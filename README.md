# ArcticVoid Discord Theme

Minimalist dark theme for BetterDiscord and Vesktop. ArcticVoid uses deep obsidian surfaces, steel gray text, cyan accents and Inter typography.

## Preview

Add screenshots here once the theme is loaded in your Discord client.

## Installation

### BetterDiscord

1. Download `ArcticVoid.theme.css`.
2. Move it to your BetterDiscord themes folder.
3. Enable `ArcticVoid` in BetterDiscord settings.

### Vesktop

1. Download `ArcticVoid.theme.css`.
2. Move it to:

```text
%APPDATA%\vesktop\themes
```

3. Reload Vesktop and enable the theme.

## Notes

Discord class names can change after client updates. If something looks wrong after an update, open an issue with a screenshot.
